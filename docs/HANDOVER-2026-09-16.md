## 5. Known product feel (live soak + UI glance)

**What feels solid (after #87 / #94 / #99 / #100 / #102–#104):**

- Switching sessions mid-tool **must not** cancel the background session; Stop / new-chat (`startSession`) must not wipe another session’s in-flight tools or permission queue.
- Stop clears busy chrome quickly (optimistic) while native cancel runs; Stop shows when streaming **or** pending tools.
- Background stream completion / empty per-session buffer must not steal selected-session chrome (`streamingContent` / reasoning / `isStreaming` / timeout).
- Permissions are session-scoped in the main shell; swarm bridge tags owning `sessionId`.
- **Closed by #102–#104:**
  - Legacy `Chat.tsx` permission modal is session-filtered and passes `permissionRequestId` on approve/deny, eliminating the cross-session FIFO `permissionQueue[0]` trap (#102).
  - Composer Send↔Stop affordance is explicit and reason-specific (shows Stop control during streaming or pending tools with titles and busy hints, unmounting Send) (#103).
  - Right `AgentPanel` Working Folders has a cleaner empty state, hides noisy "0" count badge, and uses tighter spacing for higher glance signal (#104).

**What still feels rough:**

- ~~Ask-default → Danger friction for any tool soak~~ — addressed (`fix/ask-danger-friction`: one-click Switch to Danger + upgrade/recovery copy naming Danger).
- Live providers (esp. DeepSeek) may refuse barrier tools → sleep via `execute_command` is the reliable soak probe.
